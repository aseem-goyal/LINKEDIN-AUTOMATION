# LinkedIn Recruiter Email Automation System

## Developed By
Aseem Goyal

## Tech Stack
- Python
- Selenium
- Regex
- SMTP
- ChromeDriver

## Features
- Automatic LinkedIn Login
- Job/Post Search Automation
- Recruiter Email Extraction
- Save Emails to File
- Automatic Email Sending with Resume Attachment

## How to Run
1. Install Python
2. Install Selenium
3. Add ChromeDriver
4. Run:
   python main.py
